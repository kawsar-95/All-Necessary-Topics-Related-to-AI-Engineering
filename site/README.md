# AI Engineering — Next.js site

A static Next.js port of the single-file **All Necessary Topics Related to AI
Engineering** HTML reference guides. The content is unchanged from the
originals — every section, code block, inline SVG diagram, citation link,
layman panel, and বাংলা (Bangla) panel is preserved. The wrapping is a real
Next.js app with proper navigation, dark mode, sticky table of contents, and
a per-section voice picker.

## Stack

- **Next.js 16.4** (App Router, statically generated)
- **React 19**
- **TypeScript 5**
- **Tailwind CSS 4** (CSS-first config via `@theme inline`)

## Routes

| Route                                  | What it is                                |
| -------------------------------------- | ----------------------------------------- |
| `/`                                    | Landing page — hero + 5 guide cards       |
| `/guides/llm-fundamentals`             | 10 topics, 26 sources                     |
| `/guides/prompt-engineering`           | 8 topics, 15 sources                      |
| `/guides/context-engineering`          | 7 topics, 11 sources                      |

| `/guides/agents-agentic-systems`       | 9 topics, 30 sources                      |

## How the content flows

```
*.html   ──►  scripts/extract-content.mjs  ──►  src/content/*.json
                                                       │
                                                       ▼
                                            src/lib/guides.ts
                                                       │
                                       ┌───────────────┼───────────────┐
                                       ▼               ▼               ▼
                                  app/page.tsx  guides/[slug]   components/*
```

1. **`scripts/extract-content.mjs`** reads each HTML guide and splits it
   into structured JSON: per-section `{ id, num, title, sub, body, layman,
   bangla }` plus a deduplicated, sorted `sources` list (with URLs). Run it
   when the source HTML changes.
2. **`src/lib/guides.ts`** is a typed accessor over the JSON.
3. **`src/app/page.tsx`** is the landing page; **`src/app/guides/[slug]/page.tsx`**
   renders a guide with sidebar nav, sources block, and metadata.
4. **`<SectionView>`** renders one section, exposing a per-section voice
   picker (Technical / Layman's / বাংলা / All three).
5. The original guide HTML is injected verbatim via
   `dangerouslySetInnerHTML` and styled by the `.prose-guide` rules in
   `globals.css`. Every class the original used has a rule there.
6. Each guide page links to the original single-file HTML at
   `/guides-html/<slug>.html`; the homepage also links to the standalone
   `index.html` and to every guide's original HTML. These are the source
   files copied into `public/guides-html/` and `public/index.html` so the
   Next.js server serves them as static assets.

## Running it

```bash
# 1. Install
npm install

# 2. (Optional) Rebuild the JSON if you edit the source HTML
npm run extract

# 3. Dev mode
npm run dev
# → http://localhost:3000

# 4. Production build + start
npm run build
npm run start
```

The content is fully static — `next build` prerenders every route.

## Updating the source content

The four source HTML files live in the **parent** directory (one level up
from this `site/` folder). If you edit one, run `npm run extract` to
re-emit the JSON, then `npm run build`. The build embeds the JSON into
the static output, so a rebuild is required after every extract.

When adding a new guide, add it to `GUIDES` in
`scripts/extract-content.mjs` and `src/lib/guides.ts`.

## Design notes

- The dark theme mirrors the original HTML's design tokens (`#0b0f17`
  background, `#22d3ee` cyan accent, `#a78bfa` violet for the layman
  panel, `#34d399` green for the বাংলা panel).
- Inter, JetBrains Mono, and Noto Sans Bengali are loaded via
  `next/font/google` with `display: swap` so missing-font offline builds
  still render.
- The sticky right-side TOC uses `IntersectionObserver` to highlight the
  section currently in view.
- The voice picker is per-section state — opening a new section starts
  in Technical mode, which is the most efficient for serial reading.
