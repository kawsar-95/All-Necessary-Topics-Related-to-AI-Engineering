About these references

Each guide and chapter is a single self-contained HTML file — no build step, no dependencies, no internet required. Open directly in any modern browser. All citations resolve to arXiv papers and primary vendor documentation; each ID was fetched and verified against the publisher's metadata.

The "layman's version" panel at the bottom of every section uses simple analogies so non-engineers (PMs, designers, curious developers) can follow along. Every section also ends with a বাংলা ব্যাখ্যা (Bangla explanation) panel. Engineers get diagrams, comparison tables, and runnable snippets at the same source.

Topics 1–4 are bundled into four multi-topic guides; topics 5–13 each live in their own single-topic chapter file. The same content is also rendered as a Next.js site with sidebar navigation, sticky table of contents, and a per-section voice picker — see site/ in the repo.
