About these guides

Each guide is a single self-contained HTML file — no build step, no dependencies, no internet required. Open directly in any modern browser. All citations resolve to arXiv papers and primary vendor documentation; each ID was fetched and verified against the publisher's metadata.

The "layman's version" panels at the bottom of every section use simple analogies so non-engineers (PMs, designers, curious developers) can follow along. Engineers get diagrams, comparison tables, and runnable snippets at the same source.
