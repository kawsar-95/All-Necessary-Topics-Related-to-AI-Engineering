Cost & performance optimisation

LLM bills scale with usage. Three knobs let you cut cost by 5–50× without losing quality: cascade (cheap → expensive routing), cache (semantic, prefix, output), and compress (prompt compression, distillation).

Model cascading (cheap → expensive routing)

Route easy requests to a small, cheap model; only escalate to a large, expensive one when the small model's confidence is low (use logprobs, self-critique, or a separate classifier).[20] A well-tuned cascade often reaches frontier quality at 30–70% of the cost.

# Two-tier cascade
def answer(q):
    small = call("llama-3.1-8b", q, max_tokens=200)
    if small.confidence > 0.85 or is_simple(q):
        return small.text
    return call("claude-sonnet-4-5", q, system="Refine this draft: "+small.text)

Caching: semantic, output, prompt

Caching is the single most powerful cost lever. Three kinds:

  • Semantic cache: hash embeddings of the prompt; if a near-identical prompt was answered recently (cosine > 0.95), return the cached answer. Built into GPTCache, Redis with vector search, and Helicone.[21]
  • Output cache: for deterministic tasks (extraction, classification with temperature=0), a key-value cache keyed on the input.
  • Prompt cache: provider-level (Anthropic prompt_caching, OpenAI cached_prompt) reuses the KV of the system prompt across calls. 80–90% discount on cached prefix.

Batch APIs for non-real-time workloads

OpenAI's /v1/batches, Google Batch, Together batch — submit a JSONL file, get results within 24h, at half the cost. Use for: nightly evals, bulk labelling, backfills, anything that doesn't need an answer in the next 5 seconds.

Distillation (small model from big)

Take 50,000 (prompt, big_model_answer) pairs from production (with consent), fine-tune a small open model on them. DeepSeek-R1's "distilled Qwen" line showed that a well-distilled 7B beats an un-distilled 12B on reasoning benchmarks.[22] Distillation is the only technique that simultaneously cuts cost and latency and unlocks self-hosting.

Prompt compression (LLMLingua-style)

Tools like LLMLingua remove stopwords, paraphrase verbose passages, and drop low-information tokens — often 5–20× compression with <3% quality hit.[23] Particularly powerful for long RAG contexts where most chunks are filler.

Token budgeting per feature

Allocate a monthly token budget per feature, alert at 80%, throttle at 100%. This is the operational layer that prevents one runaway feature from blowing the company's bill.

Model gateways: LiteLLM, Portkey, OpenRouter

A model gateway sits between your app and every LLM provider. It gives you: one API for OpenAI + Anthropic + Together + your own vLLM; per-key rate limits; cost tracking; retries; fallbacks; semantic caching out of the box. The three major options are LiteLLM (Python proxy), Portkey (production-grade SaaS), and OpenRouter (consumer-grade aggregator).[24]

The cost-optimisation stack. Each tier compounds with the ones above; work top-down. Tiers 1–3 are engineering, Tier 4 is procurement, Tier 5 is ops.

Three big knobs to cut your AI bill by 5–50×:

1. Cascade (route easy to cheap, hard to expensive). Don't send every question to the smartest AI. Send "what's 2+2?" to the tiny model, send "draft me a legal contract" to the big one. A small classifier (or the model's own score) decides which to use. You get almost the same quality at much less.

2. Cache (don't re-answer the same thing). If 1,000 users all ask "what's your refund policy?" within an hour, you answer once and serve the cached answer 999 times. Three kinds: semantic cache (answers to questions similar by meaning), output cache (answers to exact inputs), and prompt cache (the AI vendor remembers the start of your prompt and skips re-reading it).

3. Compress + distill (use less, or use smaller). Prompt compression strips the filler from your prompt without losing meaning. Distillation takes a small model, shows it 50,000 answers the big model gave, and trains it to give similar answers. The small model is now nearly as good as the big one — but 10× cheaper and runs on your laptop.

Other tricks:

• Batch API = "send me 10,000 questions, get answers tomorrow, half price." Great for anything not real-time.
• Token budgets = "feature Y has a $500/month budget; cut it off at 100%." So nothing burns the company's bank account by accident.
• Model gateways = "one API that talks to OpenAI + Anthropic + your self-hosted model." Tracks cost, retries, falls back when one provider is down.

The electricity-bill analogy: your AI bill is like an electricity bill — every call uses some. Caching is "remember what the previous user already paid for and share it." Cascade is "use a nightlight when you don't need a spotlight." Compression is "wrap your house in better insulation — same warmth, less energy." Distillation is "buy a smaller, more efficient fridge." Budgets are "the circuit breaker that trips if you accidentally leave every appliance on at once."
🇧🇩বাংলা ব্যাখ্যাসহজ ভাষায় বিস্তারিত

তিনটি বড় লিভার যা আপনার AI বিল ৫–৫০× কমাতে পারে:

১. Cascade (সহজ প্রসিঙ্গুলো সস্তায়, কঠিনগুলো ব্যয়বহুলায়)। প্রতিটি প্রশ্ন সবচেয়ে স্মার্ট AI-এ পাঠাবেন না। "২+২ কত?" ছোট মডেলে পাঠান, "আমাকে একটি আইনি চুক্তি ড্রাফ্ট কর" বড় মডেলে। একটি ছোট classifier (বা মডেলের নিজস্ব স্কোর) সিদ্ধান্ত নেয় কোনটি ব্যবহার করবে। প্রায় একই মান অনেক কম খরচে।

২. Cache (একই জিনিস আবার উত্তর দেবেন না)। ১,০০০ ব্যবহারকারী এক ঘণ্টার মধ্যে "আপনার refund policy কী?" জিজ্ঞেস করলে, আপনি একবার উত্তর দিন এবং ৯৯৯ বার cached উত্তর দিন। তিন ধরন: semantic cache (অর্থ দ্বারা অনুরূপ প্রশ্নের উত্তর), output cache (হুবহু একই input-এর উত্তর), এবং prompt cache (AI vendor আপনার prompt-এর শুরুটি মনে রাখে এবং পুনঃপড়া এড়িয়ে যায়)।

৩. Compress ও distill (কম ব্যবহার করুন, অথবা ছোট ব্যবহার করুন)। Prompt compression আপনার prompt থেকে অর্থ না হারিয়ে ফিলার বাদ দেয়। Distillation একটি ছোট মডেল নিয়ে, বড় মডেলের দেওয়া ৫০,০০০ উত্তর দেখায়, এবং অনুরূপ উত্তর দিতে প্রশিক্ষণ দেয়। ছোট মডেল এখন বড়টির প্রায় কাছাকাছি — কিন্তু ১০× সস্তা এবং আপনার ল্যাপটপে চলে।

অন্যান্য কৌশল:

  • Batch API = "আমাকে ১০,০০০ প্রশ্ন পাঠাও, কাল উত্তর দাও, অর্ধেক দামে।" real-time নয় এমন সবকিছুর জন্য দারুণ।
  • Token budgets = "feature Y-এর মাসে $500 বাজেট; ১০০%-এ কেটে দাও।" যাতে কোনোকিছু দুর্ঘটনাবশত কোম্পানির ব্যাংক অ্যাকাউন্ট পুড়িয়ে না ফেলে।
  • Model gateways = "OpenAI + Anthropic + আপনার স্ব-হোস্টেড মডেলের সাথে কথা বলে এমন একটি API।" খরচ ট্র্যাক করে, retry করে, একটি provider down হলে fallback দেয়।
বিদ্যুৎ বিলের উপমা: আপনার AI বিল হলো বিদ্যুৎ বিলের মতো — প্রতিটি কল কিছু ব্যবহার করে। Caching হলো "পূর্ববর্তী ব্যবহারকারী যার জন্য ইতিমধ্যে অর্থ দিয়েছেন তা মনে রাখুন এবং শেয়ার করুন।" Cascade হলো "স্পটলাইটের দরকার না হলে নাইটলাইট ব্যবহার করুন।" Compression হলো "বাড়িতে ভালো ইনসুলেশন — একই উষ্ণতা, কম শক্তি।" Distillation হলো "একটি ছোট, আরও দক্ষ ফ্রিজ কিনা।" Budgets হলো "সার্কিট ব্রেকার — দুর্ঘটনাবশত সব যন্ত্র একসাথে চালু রাখলে সেটি trip করে।"
